Editor de Animaciones — cómo se usa

1. Abrir tu proyecto

Botón Abrir carpeta del proyecto (Chrome o Edge) y elige la carpeta raíz del juego (la que contiene scripts/, objects/ y sprites/). Así puedes escribir los cambios directo en los GML, con copia de seguridad automática. En otros navegadores usa Elegir carpeta (solo lectura): te dará el archivo entero para copiar y pegar en GameMaker.

2. Elegir personaje → estado

Cada estado usa una tira de sprites (player_anims). Al elegirlo se reproduce con la velocidad que tiene HOY el archivo. El botón Demo trae un bicho de prueba para probar sin proyecto.

3. Marcar el loop («empieza aquí y termina acá»)

Arrastra los marcadores A (inicio) y B (fin) sobre la tira, o usa los botones «A aquí»/«B aquí» con el vídeo parado en el frame que quieras (teclas [ y ]). Los frames antes de A se ven UNA vez (la «entradilla»), igual que el idle del juego. Si B no es el último frame, el loop se corta ahí.

4. Velocidad

El deslizador es el image_speed del juego: frames por paso a 60 pasos/s (1 = 60 fps; 0.3 = 18 fps). Ojo: si el archivo usa una fórmula (depende de xspd) te aviso antes de reemplazarla.

5. Escribir

El panel derecho muestra el antes/después exacto de cada archivo. Escribir guarda una copia en _backups_animeditor/ y modifica Draw_76.gml (velocidad y cortes de loop) y Other_7.gml (punto de repetición: image_index = image_number - N). Después compila el juego (F5). No hace falta recompilar el server: el frame exacto viaja por red.
