QUE PASO ESTA VEZ
-----------------
Al compilar el APK con el zip v80d, GameMaker falla al final con:

    DisasterServer.java:29: error: cannot find symbol
        android.content.Context ctx = RunnerJNILib.ms_activity;
                                          ^
      symbol:   variable ms_activity

CAUSA: en tu runtime (2026.1.0.28) la clase RunnerJNILib YA NO
tiene el campo "ms_activity". Ese nombre existia en runtimes
viejos, pero la via que usan TODAS las extensiones de GameMaker
(documentada en los foros oficiales desde 2014 hasta hoy) es:

    com.yoyogames.runner.RunnerActivity.CurrentActivity

que es un campo publico y estatico de RunnerActivity — la clase
que el propio runner compila DENTRO de tu paquete (la viste en el
log: com.teamexeempire.disaster2dm). Ese era el error de mi parte:
usa una API que no existe en tu version de runtime.
