=====================================================================
 AMY CYBER GHOST v2 — fix del error "scr_amy_cyber not set"
=====================================================================

El error que viste
------------------
  ERROR in action number 1
  of Draw Event for object obj_player_puppet:
  Variable obj_player_puppet.scr_amy_cyber(101211, -2147483648)
  not set before reading it.
      at gml_Object_obj_player_puppet_Draw_0 (line 137)

La causa (NO es el codigo)
--------------------------
Exactamente la misma clase de bug que los sonidos de Sally (el
"SALLY5 not set"): las carpetas del zip v1 se copiaron al
proyecto, pero un asset copiado como ARCHIVO no existe para
GameMaker si no esta REGISTRADO en el
"Sonicexe The Disaster 2D Remake.yyp". Para el compilador,
scr_amy_cyber no es un script: es una variable que nadie asigno
-> "not set before reading it" justo en la linea 137 del Draw del
puppet (el primer sitio del juego que lo llama).

La via git del LEEME v1 tenia ese paso manual ("anade estas 2
lineas al .yyp") y por ahi se cayo. Y ojo con esa via: si editas
el .yyp a mano con el GameMaker ABIERTO, al guardar el IDE te
sobreescribe la edicion y la pierdes sin enterarte. Por eso esta
vez va todo ya parcheado de fabrica.

El fix
------
1. El .yyp de este zip YA TRAE los 2 registros nuevos:
     Scripts -> scr_amy_cyber
     Shaders -> shd_amy_cyber
   y encima conserva el fix anterior (los sonidos SALLY1-5 y
   EVASI1-3 de la fase 2 de Sally Canon siguen registrados).
2. Blindaje v2 (para que esto NO te vuelva a pasar, con ningun
   asset):
   - Los 2 Draw events preguntan ANTES de llamar al script: si
     scr_amy_cyber no esta cargado, dibujan con el palette swap
     normal de siempre (Amy clasica, cero efecto, cero crash).
   - El script busca el shader POR NOMBRE (asset_get_index): si
     shd_amy_cyber no esta cargado, cae al palette swap normal.
   O sea: si algun dia vuelve a quedar un asset fantasma, el
   juego a lo sumo se ve SIN el efecto... pero NUNCA mas explota
   con un "not set" en plena partida.

Instalacion (4 pasos, 2 minutos)
--------------------------------
1. CIERRA GameMaker del todo (si lo dejas abierto, al guardar te
   sobreescribiria el .yyp parcheado y volvemos a empezar).
2. Extrae TODO el contenido del zip sobre la raiz del proyecto
   (la carpeta donde esta el .yyp). Acepta reemplazar el .yyp, los
   2 Draw_0.gml y que se copien las 2 carpetas nuevas
   (scripts/scr_amy_cyber y shaders/shd_amy_cyber).
3. Abre el proyecto y verifica en el arbol de recursos:
     Scripts  -> scr_amy_cyber
     Shaders  -> shd_amy_cyber
4. Corre el juego con Amy Canon. El efecto es EL MISMO de la
   preview que te gusto (glitch con el rosa intacto).

Ajustes (macros en scr_amy_cyber.gml, igual que la v1)
------------------------------------------------------

                           estaba).

                           [CHARACTER_AMY_CANON, CHARACTER_AMY]

  AMY_CYBER_SPLIT    1.0    px del desdoblamiento rojo/cian.
  AMY_CYBER_GLITCH   5      px maximos de las bandas. 0 = sin bandas.
  AMY_CYBER_FLICKER  0.30   chispas + barrido + parpadeo.
  AMY_CYBER_ALPHA    0.85   opacidad holograma. 1 = solida.
  AMY_CYBER_TINT     0.15   lavado cian en las sombras.
