v2 ARREGLA EL CRASH DE LA v1
----------------------------
Error que daba la v1 justo al arrancar (en el logo):

  ERROR in action number 1
  of Create Event for object obj_achivements:
  Unbalanced surface stack. You MUST use surface_reset_target() for each
  set. {5}

CAUSA: en el blur (Draw_77 de obj_postfx) habia 6 surface_set_target()
seguidos (las 3 iteraciones horizontal/vertical encadenadas) con UN solo
surface_reset_target() al final. En GameMaker cada surface_set_target()
APILA el destino de dibujo y cada surface_reset_target() lo desapila uno
a uno: quedaban 5 apilados por frame — de ahi el {5} del error.

OJO: el evento que senala el error es enganoso (es lo tipico de este
error en GameMaker): lo reporta en el siguiente evento que corre, no en
el culpable. obj_achivements (el guardado) no tiene ni una llamada a
surfaces; el culpable era obj_postfx/Draw_77.gml.

ARREGLO: cada pasada del blur ahora cierra con su surface_reset_target()
antes del siguiente set (set -> uniforms -> draw -> reset; 7 sets / 7
resets, pila en 0 al final de cada frame). Bonus: con la pila sucia, la
composicion final (base con grading + glow) dibujaba sobre la superficie
equivocada y nunca llegaba a la ventana — la v2 es la primera version en
que el efecto se ve de verdad en pantalla.

COMO APLICAR (ya tienes la v1 puesta: solo se reemplaza 1 archivo)
------------------------------------------------------------------
  1. Cierra GameMaker.
  2. Reemplaza objects/obj_postfx/Draw_77.gml por el de este zip.
     (Opcional: scripts/check_postfx.py y este LEEME tambien cambiaron;
      el worklog.md es el registro de trabajo.)
  3. Abre el proyecto y corre con F5: el logo ya no aborta.
  4. F9 alterna el efecto en caliente para comparar con/sin.

NADA MAS CAMBIA: los 3 shaders, el Create (ajustes), el Step (F9), el
CleanUp, el spawn en obj_logo y el .yyp de la v1 quedan IGUAL.

AJUSTES (objects/obj_postfx/Create_0.gml — igual que la v1)
-----------------------------------------------------------
  threshold  = 0.72   // luminancia minima para brillar (mas bajo = brilla
                      //   mas cosa; 0.6 = casi todo lo claro resplandece)
  softKnee   = 0.35   // suavidad del umbral (0 = corte duro)
  bloomPower = 0.60   // intensidad del glow (0.3 = sutil, 1.0 = neblina)

  saturation = 1.14   // 1 = sin cambio (1.25 = muy cartoon)
  contrast   = 1.06   // 1 = sin cambio (1.15 = duro)
  liftS      = 0.030  // azul en sombras
  liftH      = 0.025  // calor en luces

  vignette   = 0.28   // oscurecido de bordes (0.5 = muy oscuro)
  aberration = 1.5    // separacion RGB (0 = sin aberracion)

Valores originales para volver atras: 0.72 / 0.35 / 0.60 / 1.14 / 1.06 /
0.030 / 0.025 / 0.28 / 1.5.
